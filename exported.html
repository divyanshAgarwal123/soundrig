Integration code
const audio = createPlayer();
await audio.start();
createGame('game', {
  state: ({speed, air, grounded, alive}) =>
    audio.set({speed, air, grounded, alive}),
  event: (name, intensity) =>
    audio.emit(name, intensity)
});
The audio bundle embeds its own processor and renderer. Phaser and the game remain ordinary host dependencies.
