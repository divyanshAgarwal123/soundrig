Your sounds, in a game you can keep.

This runner uses plain JavaScript and the exported SoundRig component. No game engine, model, authoring server or external asset request is needed.

Click the game, then hold Right to run and Up to jump. Collect the first parcel at 120 metres; jump over the barrier at 350. Movement buttons work with keyboard and touch.
