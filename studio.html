            Check definitions and game wiring
            Six checks, 30 seconds combined, 32KiB. Cue RMS measures rendered event-layer level, not human audibility. Silence windows include sound tails. Your exported adapter maps explicit raw fields and named game events; it does not infer collisions.
            In your game, configure bindings.json, forward raw state and named events. The ZIP includes a Phaser scene helper, a plain JavaScript adapter and node verify.mjs for repeat checks without a model.
            
        
            
    
            
    
            Use it in your game
            This build supports a confirmed JavaScript adapter. Map your game to these normalized controls and events; it does not automatically understand arbitrary projects.
            The host game sends state and events to the exported component:
            const audio = createPlayer();
await audio.start();
createGame('game', {
  state: ({speed, air, grounded, alive}) => audio.set({speed, air, grounded, alive}),
  event: (name, intensity) => audio.emit(name, intensity)
});
